# biblioteca-alejandria-
Este repositorio tiene como objetivo resguardar tanto la documentacion como todo material que ayude a comprender la creacion y desarrollo de proyecto de progamación 2 

## Estructura

```
docs/
├── catedra/    # documentación provista por los profesores (fuente de verdad)
│   ├── PROJECT_STATEMENT-v1.md        # enunciado del proyecto integrador
│   └── INTEGRATION_REFERENCE-v2.md    # contratos REST, Redis y Kafka con la cátedra
├── proyecto/   # documentación propia: arquitectura, contratos entre servicios, modelo de datos, seguridad
└── adr/        # decisiones de diseño (Architecture Decision Records)
```

## Repositorios del proyecto

1. `atlas-catalogo` — servicio de catálogo y sincronización
2. `cronos-turnos` — servicio de turnos y reservas
3. `hermes-app` — aplicación KMP para Android
